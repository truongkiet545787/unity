Root cause
----------
The earlier scene setup assigned the same generated smoothed asset to both the
MeshFilter and MeshCollider. The active collider therefore exposed the road
strip's low-poly triangle height transitions directly to the Rigidbody and
VehicleGroundProbe raycasts. A fitted terrain MeshCollider also overlaps the
road region; it was not deleted because it is part of island scenery and must
be validated in Play Mode before any layer/collider change.

------------------
CarController uses Rigidbody-based arcade physics and downward
Physics.RaycastNonAlloc ground probing. No WheelCollider-based fix or vehicle
physics change was made. Waypoints, boosts, triggers, ramps and bridges remain
untouched.

Validation status
-----------------
Static scene and asset references were verified. Unity runtime driving across
the full route, bridge, ramp, shortcut, boost triggers and AI behavior still
require a manual Play Mode pass because this Editor instance was not available
for runtime control during the change.
